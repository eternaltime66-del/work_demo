# Game3 · 游戏机制一览

> 术语 + 标签 · 代码为准 · 闭环无遗漏  
> 棋盘：`6×5` · 时间轴：行动值 AV · `50 AV = 1 秒`  
> **核心命题**：技能编辑器设计战力 → 挂到装备/怪物 → 玩家打怪拿材料 → 合成更强装备 → 再打怪

---

## 0. 两条主闭环（先看这个）

游戏不是「一堆独立模块」，而是 **内容生产闭环** × **玩家变强闭环** 咬合运转。

### 0.1 内容生产闭环（后台做内容）

```text
关卡树
  └─ 摆怪（LevelMonster）
       └─ 怪物（四维 + 技能槽 + 掉落表）
            └─ 掉落材料（Item / MATERIAL）
                 └─ 配方（材料清单 → 产出装备）
                      └─ 合成装备（WEAPON / 防具 / 饰品…）
                           └─ 装备挂默认技能 / 被动
                                └─ 技能来自「技能编辑器」
```

| 环节 | 标签 | 你在配置什么 | 玩家侧感受 |
|------|------|--------------|------------|
| 关卡 | `#Stage` | 单表树 TYPE→章→关→怪坐标 | 「去哪打」 |
| 怪 | `#Monster` | ATK/HP/DEF/ACTION、三技能槽、稀有度占地 | 「打谁、难不难」 |
| 材料 | `#Drop` `#MATERIAL` | 掉落率、数量区间 | 「打完能拿啥」 |
| 配方 | `#Craft` `#Recipe` | 材料清单 → 产出物×数量 | 「材料能换啥」 |
| 装备 | `#Equip` `#Item` | 面板数值 + 默认技能/被动挂载 | 「穿上变强啥」 |
| 技能 | `#SkillEditor` | 主动/被动/充能/输出/公式 | 「技能怎么打」 |

> **顺序建议（设计时）**  
> 先在技能编辑器把「普攻 / 小技能 / 大招 / 被动」做出来 → 再挂到装备或怪物 → 再配掉落与配方 → 最后用关卡把怪摆上。  
> 也可以倒着推：先定关卡节奏与掉落经济，再反推装备与技能强度。

### 0.2 玩家变强闭环（前台玩）

```text
出击打关卡怪
  → 胜利掉落材料进仓库
  → 合成：仓库材料 → 装备进战斗背包
  → 备战：背包物穿到人偶槽位
  → 属性/技能/被动生效，布局上阵
  → 再出击更难的关
  → ……循环
```

| 环节 | 标签 | 玩家动作 | 变强点 |
|------|------|----------|--------|
| 打怪 | `#Deploy` `#Battle` | 出击 → 战斗 | 消耗时间，换材料 |
| 掉落 | `#Drop` | 自动进仓库 | 资源积累 |
| 合成 | `#Craft` | 选配方合成 | 材料 → 装备 |
| 穿戴 | `#Prep` `#Equip` | 仓库↔背包↔槽位 | 面板 + 技能装配 |
| 布局 | `#Layout` | `6×5` 上阵 | 站位影响目标/AOE |
| 再打 | `#Stage` | 挑战更高关 | 验证 Build |

**一句话**：后台用技能编辑器「设计战力零件」，用装备把零件打包成可掉落/可合成的成长台阶；玩家只做 **打怪 → 合成 → 穿戴 → 再打怪**。

### 0.3 后台编辑装备 → 编辑技能 → 设计技能

这是内容侧最重要的操作链，技能编辑器是中心：

```text
① 技能编辑器
   ├─ 主动技能：类型 / 流派 / 元素 / 所需充能 / 充能条件 / 输出
   ├─ 被动技能：战外 OUT_* / 战内 BATTLE_* / 条件 / 输出
   └─ BUFF 定义：属性 / 脉冲 / 判定 / 闪避（可被输出引用）

② 编辑装备（或怪物）
   ├─ 填面板：攻击、生命、防御、攻速…
   ├─ 挂默认主动：武器普攻覆盖、默认小技能/大招
   └─ 挂默认被动：基础/高级属性、开战/判定/脉冲/战斗事件

③ 编辑经济与关卡
   ├─ 怪物掉落 → 材料
   ├─ 配方 → 材料换装备
   └─ 关卡摆怪 → 玩家能打到这条线
```

| 后台模块 | 标签 | 职责一句话 |
|----------|------|------------|
| 充能技能 | `#ActiveSkill` | 设计「出手时做什么、怎么攒充能」 |
| 被动 | `#Passive` | 设计「穿上常驻 / 开战触发 / 事件触发」 |
| BUFF | `#BuffDef` | 设计可挂到目标上的持续态 |
| 装备 | `#Item` | 把技能零件组装成一件可穿戴物 |
| 怪物 | `#Monster` | 敌方战力 + 掉落出口 |
| 配方 | `#Recipe` | 材料 → 装备的兑换门 |
| 关卡树 | `#Stage` | 把怪摆进可挑战进度 |

玩家侧 **不造技能**，只消费后台挂好的结果。

## 1. 技能编辑器（重点）`#SkillEditor`

技能编辑器是整套成长的「零件工厂」。  
**核心范式**：主动技能 = **被动充能 → 达标解锁 → 行动时自动释放**（无固定 CD）；被动 = **条件/锚点 → 输出**；一切数值语言统一走 **公式 + 目标槽 + 匹配槽**。

### 1.1 编辑器产出什么

| 产出 | 标签 | 挂载去向 |
|------|------|----------|
| 主动技能 | `#ActiveSkill` | 角色基底 / 武器普攻 / 装备默认充能技 / 怪物三槽 |
| 被动技能 | `#Passive` | 装备默认被动（战外 OUT + 战内 BATTLE） |
| BUFF 定义 | `#BuffDef` | 被输出 `APPEND_BUFF` 引用 |
| 公式片段 | `#Formula` | 充能阈值、伤害、判定、被动条件共用 |

设计一条主动技的填表顺序：

```text
身份 → 所需充能 → 充能条件(可多条) → 输出(可多条) → 次数上限(可选)
```

---

### 1.2 主动技能核心 `#ActiveSkill`

#### 身份

| 字段 | 枚举/值 | 说明 |
|------|---------|------|
| skillType | `NORMAL` 普攻 · `SMALL` 小技能 · `ULTIMATE` 大招 | 出手优先级；普攻通常无门槛 |
| skillSchool | 自定义字符串，默认 `无` | `#流派`；供 Match / 战中计数 |
| damageElement | `PHYSICAL` `POISON` `IGNITE` `FREEZE` `SHOCK` `BURN` | `#元素`；技能身份元素（输出伤害可另配） |

#### 所需充能 `#NeedCharge`

| 模式 | 含义 |
|------|------|
| `SELF_BASE_ACTION` | 门槛 = 自身**基础行动值** |
| `MANUAL` | 手填 `needCharge` 点数 |
| `FORMULA` | `needChargeFormulaJson` 公式求阈值 |

每技能一条独立充能条；释放时 `spendCharge` 扣门槛值。

#### 充能条件 `#SkillCharge`（可多条，增益叠加）

| `ChargeConditionType` | 机制 |
|-----------------------|------|
| `ACTION_VALUE` | 每经过 `everyActionValue` AV → `chargeGain` |
| `SKILL_CHARGE` | 技能事件触发 → +gain；再配事件方向 + `#Match` |
| `TAKE_ANY_DAMAGE` | 受到任意伤害 → +gain |
| `DEAL_ANY_DAMAGE` | 造成任意伤害 → +gain |
| `DEAL_KILL` | 造成击杀 → +gain |

`SKILL_CHARGE` 方向 `SkillChargeEvent`：

| 值 | 含义 |
|----|------|
| `CAST` | 自己**释放**匹配技能时 |
| `RECEIVE` | 自己**受到**匹配技能时 |

> 例：释放「普攻类型」充能 +1 → 正常普攻即可推进小技能条。

#### 释放次数上限（0 / null = 不限）

| 字段 | 含义 |
|------|------|
| `maxCastSkill` | 本技能本场最多释放次数（引擎主要校验项） |
| `maxCastGlobal` / `maxCastAllMeans` / `maxCastRole` | 预留：全局 / 所有手段 / 本角色维度 |

#### 出手与连发（战斗侧，编辑时要心里有数）

| 机制 | 标签 | 规则 |
|------|------|------|
| 选技 | `#CastPick` | 充能就绪且未超限 → **优先非普攻**（列表首个就绪充能技），否则普攻 |
| 连发 | `#ChainCast` | 本回合首段释放后，最多再连发 **8** 次「非普攻且充能已满」 |
| 无 CD | — | 节奏完全由充能条件 + ACTION 出手节奏决定 |

---

### 1.3 技能匹配槽 `#Match`（三处共用）

同一套 `SkillChargeMatchMode`，用于：**充能条件** · **战斗事件被动** · **公式读取技能次数**。

| 模式 | 含义 | 附带字段 |
|------|------|----------|
| `ANY` | 任意技能 | — |
| `ANY_TYPE` | 指定类型 | `matchSkillType`：普攻/小技能/大招 |
| `ANY_SCHOOL` | 指定流派 | `matchSkillSchool` |
| `ANY_ELEMENT` | 指定元素 | `matchDamageElement` |
| `SPECIFIC` | 指定技能 | `matchSkillId` |

战中计数维度 `SkillCountScope`：`ANY` / `SKILL_TYPE` / `SKILL_SCHOOL` / `SKILL_ELEMENT` / `SPECIFIC_SKILL`  
方向 `SkillCountDirection`：`CAST` 释放 · `RECEIVE` 受到。

---

### 1.4 输出 `#SkillOutput`（主动 / 被动共用）

挂在 `skillId` 或 `passiveSkillId` 上，按 `sort` 顺序结算。

#### 种类 `SkillOutputKind`

| 种类 | 标签 | 必配要点 |
|------|------|----------|
| `EFFECT` | `#伤害` `#治疗` | `effectType`=`DAMAGE`/`HEAL` · 目标 · 元素 · 公式 · 段数 · 触发率 |
| `ATTR` | `#属性修改` | 目标 · `attrKey` · `attrDir` · 公式 · `durationAv`（0=战斗内永久） |
| `APPEND_BUFF` | `#挂BUFF` | 目标 · `buffDefId`（含闪避等各类 BuffDef）· 触发率 |

#### 公共字段

| 字段 | 机制 |
|------|------|
| `targetType` | 通用目标槽（见 §1.5） |
| `formulaJson` | 伤害/治疗/属性数值公式 |
| `hitSegments` | 分段结算，默认 ≥1；展示可写作 `× N` |
| `triggerRate` | null/≥100 必中；`0` 永不；否则按 % 掷骰 |
| `damageElement` | EFFECT 伤害用（可与技能身份元素不同） |
| `durationAv` | ATTR 持续；**50 AV = 1 秒**（展示）；BUFF 持续在 BuffDef |

#### 可改属性键 `AttrModifyKey`

| 组 | 键 |
|----|-----|
| 基础 | `ATK` · `MAX_HP` · `DEF` |
| 高级 | `LIFE_STEAL` · `ATK_SPEED` · `DEAL_DMG_RATIO` · `TAKEN_DMG_RATIO` · `DEAL_ELEMENT_DMG_RATIO` · `TAKEN_ELEMENT_DMG_RATIO` · `DEAL_PHYS_DMG_RATIO` · `TAKEN_PHYS_DMG_RATIO` · `FINAL_ATK` · `FINAL_HP` · `FINAL_DEF` |

方向：`INCREASE` / `DECREASE`。

#### 伤害来源分类（锚点/事件用）`DamageSourceKind`

`ACTIVE_SKILL` 主动技能伤 · `PASSIVE` 被动伤 · `PULSE_BUFF` 脉冲 BUFF 伤  
→ 决定哪些 `CombatEvent` / 统计会被触发（脉冲伤**不是**主动技能伤害）。

摘要文案风格：

```text
对 战场首位敌方 造成 物理伤害 自己·攻击
50% 对 自己 增加攻击 自己·攻击 × 0.2（持续 2秒）
对 敌方全部 追加BUFF（持续 4秒）
```

### 1.5 通用目标槽 `#Target`（`SkillEffectTarget`）

战场 `6×5`；**首位**按排扫描：每排左→右，找到第一个存活单位。

| 大类 | 枚举（节选） |
|------|----------------|
| 自身 | `SELF` |
| 己方单体 | `ALLY_FIRST` · `RANDOM_ALLY` · `ALLY_MAX_HP` / `MIN_HP` · `ALLY_MAX_MAX_HP` / `MIN_MAX_HP` · `ALLY_MAX_HP_PCT` / `MIN_HP_PCT` · `ALLY_MAX_ATK` / `MIN_ATK` |
| 己方群体 | `ALL_ALLY` · `ALLY_FRONT_ROW` · `ALLY_BACK_ROW` |
| 敌方单体 | `FIRST`（战场首位敌方）· `RANDOM_ENEMY` · `ENEMY_MAX_*` / `MIN_*`（HP / MAX_HP / HP_PCT / ATK） |
| 敌方群体 | `ALL_ENEMY` · `FRONT_ROW` · `BACK_ROW` |
| 全场 | `ALL_FIELD` · `FIELD_*` · `FIELD_FRONT_ROW` · `FIELD_BACK_ROW` |
| 事件专属 | `EVENT_HIT_TARGETS` 本次受击目标 · `EVENT_CASTER` 施法者 · `EVENT_DAMAGE_SOURCE` 伤害来源 · `EVENT_PULSE_CASTER` 脉冲施法者 · `EVENT_KILLER` 击杀方 · `EVENT_KILLED` 被击杀方 · `SPECIFIC_TARGET` |

> 战斗事件被动优先用「事件专属目标」，否则容易打偏。

### 1.6 被动技能核心 `#Passive`

#### 类型总表 `PassiveSkillType`

| 类型 | 域 | 机制摘要 |
|------|----|----------|
| `OUT_BASIC` | 战外 | 平坦攻/血/防 → 子表 `PassiveEffect`，开战前固化 |
| `OUT_ADVANCED` | 战外 | 吸血/攻速/伤害比例/最终比例等 → `PassiveEffect` |
| `BATTLE_START` | 战内 | 开战锚点：立即 / 达 AV 一次 / 每 AV 脉冲 |
| `BATTLE_JUDGE` | 战内 | 左公式 `CompareOp` 右公式：**上升沿触发一次**；不成立可撤销 ATTR |
| `BATTLE_PULSE` | 战内 | 条件维持期间可循环触发；可配 `maxTriggerPerBattle` |
| `BATTLE_COMBAT` | 战内 | 战斗事件后触发 + `#Match` 过滤 |
| `IN_*`（旧） | 兼容 | `IN_ANCHOR` / `IN_PERIODIC` / `IN_SUSTAINED` → 新内容用 BATTLE_* |

战内结果一律走 `#SkillOutput`（不再用旧 combatEffect 做主路径）。

#### 前置条件模式

| `conditionMode` | 含义 |
|-----------------|------|
| `UNLIMITED` | 始终生效（摘要：「始终生效」） |
| `SELECT` | 走条件组；**多条同时满足**；空组≈放行 |

#### 条件类型 `PassiveConditionType`

| 类型 | 含义 |
|------|------|
| `EQUIP_ITEM` | 装备了指定物品 |
| `EQUIP_ITEM_TYPE` | 装备了某 `ItemType`（武器/甲/手/头/腿/饰…） |
| `EQUIP_SKILL` | 装配了指定技能 |
| `EQUIP_SKILL_TYPE` | 装配了某主动技能类型 |
| `FORMULA_COMPARE` | 左公式 `CompareOp` 右公式 |

`CompareOp`：`GT` `GTE` `LT` `LTE` `EQ`。

#### 开战锚点 `BATTLE_START`

| `BattleStartApplyRule` | 机制 |
|------------------------|------|
| `IMMEDIATE` | 开战立即触发一次 |
| `AT_ELAPSED_ONCE` | 全局经过 `startElapsedAv` 后触发**一次** |
| `EVERY_ELAPSED` | 每经过 `startElapsedAv` **脉冲一次** |

#### 判定 / 脉冲锚点

共用：`leftFormulaJson` + `compareOp` + `rightFormulaJson`  
- **判定**：条件从假→真的**边沿**打一次；假时可撤 ATTR  
- **脉冲**：阈值达标可反复；用 `maxTriggerPerBattle` 刹车

#### 战斗事件 `BATTLE_COMBAT` · `CombatEventType`

| 事件 | 含义 | 备注 |
|------|------|------|
| `AFTER_DEAL_ACTIVE_DMG` | 造成主动技能伤害后 | 不含脉冲 BUFF 伤 |
| `AFTER_TAKE_ACTIVE_DMG` | 受到主动技能伤害后 | |
| `AFTER_CAST_SKILL` | 释放技能后 | 可套 `#Match` |
| `AFTER_RECEIVE_SKILL` | 受到技能后 | 可套 `#Match` |
| `AFTER_TAKE_PULSE_BUFF_DMG` | 受到脉冲 BUFF 伤害后 | |
| `AFTER_KILL` | 击杀时 | 任意致死伤害后；专属目标 `EVENT_KILLER` / `EVENT_KILLED` |
| `AFTER_KILLED` | 被击杀时 | 死者仍可触发；专属目标同上 |
| `AFTER_DODGE` | 触发闪避后 | 闪避者触发；攻击者为事件对方 / 伤害来源；可套 `#Match` |

#### 战外效果叠乘（`PassiveEffect`）

| 叠乘 | 含义 |
|------|------|
| `ADD_FLAT` | 点数加减（攻/血/防） |
| `ADD_PERCENT` | 百分比加法（含最终比例类） |
| `MULT_PERCENT` | 百分比叠乘（`1±n%`） |

### 1.7 BUFF 定义 `#BuffDef`

由输出 `APPEND_BUFF` 挂上目标。

| 字段 | 机制 |
|------|------|
| `buffKind` | 见下表 |
| `beneficial` | 是否有益 |
| `dispelable` | 是否可驱散 |
| `stackMode` | `NONE` 不叠 · `STACK` 叠层（+刷新时长） |
| `maxStacks` | 最大层数 |
| `durationAv` | 持续；0/null ≈ 战斗内永久 |

| `BuffKind` | 机制 |
|------------|------|
| `ATTR` | 挂属性修正（键/方向/公式） |
| `PULSE` | 每 `pulseEveryAv` 脉冲：伤/疗 · 元素 · 脉冲目标 · 公式 |
| `JUDGE_ATTR` | 持续判定成立 → 改属性 |
| `JUDGE_BURST` | 持续判定成立 → 爆发式输出 |
| `DODGE` | 闪避：`dodgeChance` + `skillMatchMode` 五维筛选；持续用 `durationAv` |

**闪避结算**：目标持有 `BuffKind.DODGE` 期间，受到**带技能上下文**的伤害时，若命中技能匹配 `skillMatchMode`（`ANY` / `ANY_TYPE` / `ANY_SCHOOL` / `ANY_ELEMENT` / `SPECIFIC`），按 `dodgeChance` 掷骰；成功则该次伤害为 **0**，不触发「造成/受到主动技能伤害后」，改为触发战斗事件 `AFTER_DODGE`（触发方=闪避者，对方=攻击者）。主动/被动技能通过 `APPEND_BUFF` 挂载该定义即可。

> 脉冲伤 = `#PULSE_BUFF` 来源，**不**触发「主动技能伤害后」类事件。

### 1.8 公式系统 `#Formula`

Token JSON：`kind`=`PARAM`|`OP`；运算符 `+ − * /` 与括号。  
`PARAM`：`LITERAL` 字面量，或读取（`readRole` + `readCategory` + 细分字段）。

#### 读取角色 `FormulaReadRole`

| 角色 | 含义 |
|------|------|
| `SELF` | 拥有者自己 |
| `GLOBAL` | 全局（如已经过行动值） |
| `ALL_ENEMY` / `ALL_ALLY` | 敌/我存活单位求和 |
| `EACH_TARGET` | 对每个命中目标分别求 |
| 锚点系 | `ANCHOR_HIT_TARGET` · `ANCHOR_CASTER` · `DAMAGE_SOURCE` · `EACH_DAMAGED_TARGET` · `SPECIFIC_TARGET` |

#### 读取类 `readCategory`

| 类 | 读什么 |
|----|--------|
| `ATTR` | `MAX_HP` `HP` `ATK` `DEF` `ACTION` `ELAPSED_ACTION`；以及治疗/伤害统计量、元素加成等 |
| `DAMAGE` | `damageSide`=`DEAL`/`RECEIVE` · `damageMetric`=`AMOUNT`/`COUNT`/`ACTIVE_COUNT` |
| `SKILL` | 释放/受到次数 × `#Match`（类型/流派/元素/指定） |
| `ANCHOR` | 本帧 `HIT_DAMAGE` / `SKILL_DAMAGE` |

#### 战中统计板 `#BattleStatBoard`（公式的数据源）

累计并可供读取：

- 全局已经过 AV  
- 单位当前属性  
- 造成/受到：**伤害量、伤害次数、主动技能伤害次数**  
- 治疗量 / 治疗次数  
- 按「角色 × 方向 × ANY/类型/流派/元素/指定技能」的释放/受到次数  

没有统计板，判定锚点 / 技能次数公式就无法闭环。

---

### 1.9 装配：技能如何进战斗

```text
角色 PlayerRoleSkill（基底主动）
  → 武器 ItemDefaultSkill：可覆盖全部普攻
  → 装备默认充能技（slotNo；合并去重；受 chargeSkillSlotCount 限制）
  → 装备 ItemDefaultPassive：
        OUT_* → 开战前并入面板
        BATTLE_* → 引擎挂载（先过 conditionMode）
  → 怪物：normal / small / ultimate 三槽（空普攻 → DEFAULT_NORMAL）
```

备战页技能槽 1–8 = 上述装配结果的可读投影。

#### 战斗时序（与编辑强相关）

| 术语 | 规则 |
|------|------|
| 全局 AV | 每 tick +1；展示 `50 AV = 1 秒` |
| 行动条 | 单位 `actionProgress` 攒满自身 `ACTION` → 出手并清零 |
| 同 tick 顺序 | 阵营 → `posRow` → `posCol` |
| 输出顺序 | 按配置 `sort` |
| BUFF | 按剩余 AV 到期；脉冲按 `pulseEveryAv` tick |

### 1.10 核心机制速查（配表时对照）

| 你想做… | 用什么 |
|---------|--------|
| 普攻攒小技能 | 充能 `SKILL_CHARGE` + `CAST` + `ANY_TYPE=NORMAL` |
| 时间到了开大 | 充能 `ACTION_VALUE` 或被动 `BATTLE_START`/`EVERY_ELAPSED` |
| 开场延迟炸一下 | `BATTLE_START` + `AT_ELAPSED_ONCE` |
| 血量低于 50% 触发 | `BATTLE_JUDGE` + 公式比较 `HP/MAX_HP` |
| 普攻附带额外伤 | `BATTLE_COMBAT` + `AFTER_CAST_SKILL` + Match 普攻 |
| 中毒 DoT | 输出 `APPEND_BUFF` → BuffDef `PULSE` + 元素 `POISON` |
| 套装激活 | 被动 `conditionMode=SELECT` + `EQUIP_ITEM`/`TYPE` |
| 按「火系技能释放次数」缩放 | 公式 `SKILL` + `ANY_ELEMENT=IGNITE` |
| 反击受击者 | 事件被动 + 目标 `EVENT_DAMAGE_SOURCE` / `EVENT_CASTER` |
| 限制大招只放 1 次 | `maxCastSkill = 1` |

## 2. 关卡 → 怪 → 材料 → 配方 → 合成装备

这一条是 **经济与成长台阶** 的骨架。技能再强，也要靠这条链让玩家「打得到、合得成、穿得上」。

### 2.1 关卡树 `#Stage`

```text
单表 app_stage（parent_id 树）
  TYPE（主线等） → CHAPTER（大关） → LEVEL（小关） → 摆怪 LevelMonster
```

| 要点 | 说明 |
|------|------|
| 节点 | `kind` = `TYPE` / `CHAPTER` / `LEVEL`；根 `parent_id` 为空 |
| 开战 | 仍用小关 id（`LEVEL`） |
| 坐标 | 左上锚点 `(col,row)` |
| 占地 | 不重叠、不越界 `6×5` |
| 职责 | 只负责「这一关站哪些怪」；掉落不挂关卡 |

### 2.2 怪物 `#Monster`

| 配置块 | 标签 | 说明 |
|--------|------|------|
| 四维 | ATK / HP / DEF / ACTION | 敌方基础战力 |
| 技能槽 | NORMAL · SMALL · ULTIMATE | 引用技能编辑器产物 |
| 稀有度占地 | NORMAL`1×1` · RARE`1×2` · EPIC`2×2` · BOSS`2×4` · SPECIAL 可调 | 占格与压迫感 |
| 普攻空槽 | 回退 `DEFAULT_NORMAL` | 防空指针 |

怪物技能与玩家技能 **共用同一套编辑器**，难度差异主要来自数值、站位、技能组合。

### 2.3 掉落 `#Drop`

- 挂在**怪物**上，不挂关卡  
- 每条：`dropRate`% **独立掷骰** · `min~max` 数量  
- **仅胜利**结算，入 **仓库**  
- 掉落物通常是 `#MATERIAL`，偶可直接掉装备（视配置）

### 2.4 配方与合成 `#Recipe` `#Craft`

| 术语 | 要点 |
|------|------|
| 配方 | 材料清单（从**仓库**扣） |
| 产出 | 物品 × 数量 → 进入 **战斗背包** |
| 章节锁 | `unlockChapterId`：进入该主线章节（章内任一关可打）即解锁；空=不限。例：进第一章解锁一章装；打穿一章进入二章后解锁二章装 |
| 设计意图 | 把「打怪产出」兑换成「可穿戴战力台阶」 |

```text
仓库材料 ──合成──► 背包装备 ──穿戴──► 槽位生效
（配方可见性受 unlockChapterId 约束）
```

### 2.5 装备作为「技能打包袋」`#Item`

| 类型 | 面板 | 技能挂载习惯 |
|------|------|--------------|
| 武器 | 攻击 · 攻速 | `#普攻绑定` + `#默认充能技能` |
| 防具类 | 生命 · 防御 | `#默认被动`（OUT + BATTLE） |
| 饰品 | 攻速等 | `#默认被动` |
| 材料 | 品级 | 不进战斗，只进配方 |

装备详情展示：普攻（下划线可点）· 充能技能编号列表 · 被动编号列表；摘要文案与技能详情同风格（秒、对目标造成元素伤害…）。

## 3. 角色装备变强 → 继续打怪

### 3.1 三层库存

| 层 | 标签 | 说明 |
|----|------|------|
| 仓库 | `#Warehouse` | 长期囤积；掉落入口；合成扣料处 |
| 战斗背包 | `#Bag` | 出战物资源；合成出口 |
| 穿戴 | `#Equip` | 槽位真正生效 |

仓库嵌在备战里，不是底栏独立 Tab。

### 3.2 穿戴槽 `#EquipSlot`

`WEAPON` · `ARMOR` · `GLOVES` · `HELMET` · `LEGS` · `ACCESSORY×3`

### 3.3 属性结算 `#EquipBonus`

```text
(角色Base + Extra + 装备面板 + OUT被动) × FinalRatio
ACTION ← 攻速相关换算
```

| 术语 | 标签 | 要点 |
|------|------|------|
| 基础属性 | `#Base` | ATK / HP / DEF / ACTION |
| 额外属性 | `#Extra` | 养成叠加层 |
| 最终比例 | `#FinalRatio` | 最终攻击/生命/防御比例 |
| 攻速 | `#AtkSpeed` | 增减% → 影响 ACTION |
| 伤害比例 | `#DmgRatio` | 造成/受到 · 物理/元素 |
| 吸血 | `#LifeSteal` | 造成伤害回血% |

### 3.4 玩家界面闭环

| Tab | 标签 | 职责 |
|-----|------|------|
| 首页 | `#Home` | 账号 HUD · 布局预览 |
| 备战 | `#Prep` | 人偶穿戴 · 仓库覆盖 · 战斗背包 · 技能槽预览 |
| 布局 | `#Layout` | 己方单位上阵 `6×5` · 主角锁定 |
| 合成 | `#Craft` | 仓库材料 → 产出进背包 |
| 出击 | `#Deploy` | 关卡树 → 预览怪 → 开战 |

### 3.5 战斗引擎（变强后的验证场）`#Battle` `#AV`

| 术语 | 标签 | 规则 |
|------|------|------|
| 全局行动值 | `#ElapsedAV` | 每 tick +1 · 战斗时钟 |
| 行动进度 | `#ActionProgress` | 攒满 ≥ ACTION 出手 |
| 出手选择 | `#CastPick` | 优先已充能非普攻 → 否则普攻 |
| 连放 | `#ChainCast` | 充能技能可连续（受次数上限） |
| 超时 | `#DRAW` | 达上限未分胜负 |

胜负：`WIN` · `LOSE` · `DRAW` → **仅胜利掉落**。

伤害简式：

```text
防御力减伤比例 = 攻击方攻击 ÷ (攻击方攻击 + 防御方防御)
防御后 = max(1, round(公式伤害 × 该比例))
→ × 造成/受到比例(物/元素) → 元素加减 → 吸血
```

敌我共用 `6×5`；首目标按排位扫描存活单位。

## 4. 设计工作流（推荐操作顺序）

把「技能编辑器」嵌进日常配表节奏：

### 步骤 A · 定一条成长线

1. 选定关卡进度节点（例如第 3 章某关）  
2. 定该节点 Boss/精英的强度与技能风格  
3. 定掉落材料与「下一件关键装备」配方  
4. 反推该装备应提供的面板 + 技能包

### 步骤 B · 技能编辑器做零件

1. 做武器普攻（稳定输出、可充能）  
2. 做 1～2 个充能小技能/大招（节奏差异）  
3. 做 OUT 被动（面板）+ 1 个有辨识度的 BATTLE 被动  
4. 需要持续态时先建 BuffDef，再在输出里挂上

### 步骤 C · 组装与投放

1. 编辑装备：填面板、挂默认技能/被动  
2. 编辑配方：材料 ↔ 装备  
3. 编辑怪物掉落：保证材料可获得  
4. 关卡摆怪：玩家能打到  
5. 用玩家号走一遍：打怪 → 合成 → 穿戴 → 再打，检查节奏

### 步骤 D · 迭代

- 打不过：调怪数值 / 技能，或提前投放过渡装备  
- 太简单：加怪技能组合，或提高合成门槛  
- 技能不清晰：回到编辑器改输出与充能文案，前台摘要会跟着变
