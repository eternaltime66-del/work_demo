## 1. 体系总览与推荐配置顺序

```text
后台配置流（建议）
  ① BUFF 配置（若技能要挂状态）
  ② 充能技能管理（主动技：充能 + 输出）
  ③ 被动技能各子页（基础/高级/开战/判定/脉冲/事件）
  ④ 装备管理 → 普攻 / 充能技能 / 被动技能 挂槽
     或 怪物角色管理 → 普攻槽 / 小技能槽 / 大招槽
  ⑤ 关卡模式 → 小关布置怪物；物品系统 → 掉落 / 配方
        ↓
开战装入 BattleRuntimeUnit → AV 推进 → 充能 / 出手 → 输出结算
```

核心范式：

- **无传统 CD**；主动技靠各自充能条。  
- **无全局能量池**；每个主动技能独立 `charge[skillId]`。  
- **输出统一**：主动 / 战斗被动都写 `SkillOutput`（属性 / 效果 / 追加 BUFF）。

## 3. 时间轴与出手（引擎）

每 tick：

```text
1. elapsedAV += 1
2. 按各技能「充能条件-行动值」结算 +y
3. 小技能 / 大招若 charge ≥ need → 立刻释放（不等行动条）
4. BUFF 到期 / 脉冲 / 开战规则
5. 每单位 actionProgress += 1
   若 ≥ ACTION → 出手：优先已就绪非普攻，否则普攻；再连锁满充能技（最多 8 次）
```

同 tick 顺序：阵营（己→敌）→ 行 → 列。  
**ACTION** = 出手间隔阈值；展示攻速 ≈ `100 / ACTION`。玩家与怪同一套自动逻辑。

## 4. 属性：基础 / 高级（完整清单）

后台路径：

- `技能管理 → 基础属性被动 → 基础属性`  
- `技能管理 → 基础属性被动 → 高级属性`

抽屉结构：

1. 名称 / 编码 / 排序 / 启用 / 备注  
2. **第一部分 · 生效条件**（不限 / 选择，见 §9.0）  
3. **第二部分 · 技能效果** →「添加效果」行：属性 + 增减 + 数值  

目标固定为「自己」，不可改（界面灰掉）。

### 4.1 基础属性（`OUT_BASIC`）下拉

| 后台文案 | 键 | 单位 |
|----------|-----|------|
| 攻击 | `ATK` | 点 |
| 生命 | `MAX_HP` | 点 |
| 防御 | `DEF` | 点 |

叠法：多条相加。

### 4.2 高级属性（`OUT_ADVANCED`）下拉——完整 11 项

标签会显示「数值(%)」。

#### 加法 %

| 后台文案 | 键 | 含义 |
|----------|-----|------|
| 吸血（加法） | `LIFE_STEAL` | 造成最终伤害后按 % 吸血 |
| 攻速（加法） | `ATK_SPEED` | 参与 ACTION 计算 |
| 最终攻击（加法%） | `FINAL_ATK` | 对 ATK 再乘最终比例 |
| 最终生命（加法%） | `FINAL_HP` | 对最大生命 |
| 最终防御（加法%） | `FINAL_DEF` | 对防御 |

#### 叠乘 %（默认乘数 1.0，多条按序 ×）

| 后台文案 | 键 |
|----------|-----|
| 造成伤害比例（叠乘） | `DEAL_DMG_RATIO` |
| 受到伤害比例（叠乘） | `TAKEN_DMG_RATIO` |
| 造成元素伤害比例（叠乘） | `DEAL_ELEMENT_DMG_RATIO` |
| 受到元素伤害比例（叠乘） | `TAKEN_ELEMENT_DMG_RATIO` |
| 造成物理伤害比例（叠乘） | `DEAL_PHYS_DMG_RATIO` |
| 受到物理伤害比例（叠乘） | `TAKEN_PHYS_DMG_RATIO` |

**战内**主动输出「属性」、BUFF「属性 BUFF」用同一套键（后台 `ATTR_MODIFY_KEY_OPTIONS`，文案带「%（叠乘）」等）。

## 5. 伤害结算

### 5.1 防御力减伤比例

```text
防御力减伤比例 = 攻击方攻击 ÷ (攻击方攻击 + 防御方防御)
防御后基础伤害 = max(1, round(公式伤害 × 防御力减伤比例))
```

例：攻击 100、防御 100 → 比例 0.5 → 公式伤打出一半；防御 0 → 比例 1 → 全额。  
攻防之和为 0 时按全额处理。

### 5.2 完整流水线

```text
① 公式 amount = eval(formulaJson)
② 防御后 = amount × 攻击/(攻击+防御)   → max(1, round)
③ × 造成/受到伤害比例 × 物理或元素两侧比例
④ × (1+元素加成) × (1−元素抗性)
⑤ max(1, round) → DODGE 成功则 0 → 吸血% 回复
```

无暴击 / 穿透 / 命中。元素只是伤害标签；硬控靠 BUFF。  
实现：`DamageRatioUnit.afterDefense` → `finalizeDealt`。

## 6. 充能技能管理（主动技抽屉）

路径：`技能管理 → 充能技能管理` →「+ 新增技能」或行内「编辑」。

列表可按类型筛：普攻 / 小技能 / 大招。

### 6.1 顶栏身份字段（与界面一致）

| 标签 | 说明 |
|------|------|
| 名称 / 编码 | 展示与检索 |
| 类型 | 普攻 `NORMAL` / 小技能 `SMALL` / 大招 `ULTIMATE`（从装备「普攻」入口打开时类型可能锁定） |
| 流派 | 文本，datalist 建议，默认「无」；给充能匹配 / 被动匹配用 |
| 元素类型 | 物理 / 中毒 / 点燃 / 冰冻 / 电击 / 灼烧 |
| 排序 / 备注 | — |

若从 **武器 → 普攻** 进入，顶栏有黄条：「武器普攻：保存后绑定到××普攻槽」；可「清空绑定」。

### 6.2 区块「充能」

#### 所需充能（三颗 choice-pill）

| 按钮文案 | 模式 | 操作 |
|----------|------|------|
| 自己的基础行动值 | `SELF_BASE_ACTION` | 无需再填；释放时 need = 施法者 ACTION |
| 手动输入 | `MANUAL` | 出现数字框「输入所需充能值」 |
| 公式读取 | `FORMULA` | 出现公式画布；保存为 `needChargeFormulaJson` |

#### 充能条件（可多条）

工具条：

1. 下拉选类型：`充能条件-行动值` / `充能条件-技能充能`  
2. 若选技能充能：再选 **事件**、**范围**（及类型/流派/元素/技能）  
3. 点「添加充能条件」  

每条草稿行字段：

| 条件类型 | 行内字段 |
|----------|----------|
| 行动值 | 名称；每经过行动值 **x**；增加充能 **y** |
| 技能充能 | 名称；事件；范围；…；增加充能 |

页脚灰字：

> 行动值：全局每经过 x 行动值 +y 充能。技能充能：释放 / 受到 / 造成伤害 / 受到伤害 / 造成击杀（匹配技能）时 +y。

### 6.3 区块「释放与效果」

- **本技能最大释放次数**：无限 / 手动输入  
- 「添加输出」→ 多张「输出 #N」卡片（§8）  
- 底栏「保存」→ 写入主动技 + `SkillCharge` + `SkillOutput`

## 7. 充能机制（对应后台字段）

### 7.1 规则摘要

| 规则 | 说明 |
|------|------|
| 独立条 | 每技能自己的 charge |
| 无上限 | 可超过 need |
| 多条件 | 各条件触发时分别 +y |
| 满则放 | `charge ≥ need`；小/大可本 tick 立刻 flush |
| 释放扣 | `spendCharge(need)`，前端条跟 CAST 事件的剩余 cur |

`SKILL_CHARGE` 条件**不会**给普攻技能加充能（引擎跳过）；普攻一般用「行动值」+「自己的基础行动值」。

### 7.2 行动值条件（后台填 x / y）

```text
应得 = floor(elapsedAV / x) × y
本 tick 增量 = 应得(今) − 应得(上)
```

例：x=120, y=24, need=24 → 约每 120 全局 AV 满一次。

### 7.3 技能充能 · 事件下拉（完整）

| 后台文案 | 枚举 | 何时 +y |
|----------|------|---------|
| 释放 | `CAST` | 自己释放匹配技能后 |
| 受到 | `RECEIVE` | 自己被匹配技能命中后 |
| 造成伤害 | `DEAL_DAMAGE` | 自己用匹配技能造成伤害后 |
| 受到伤害 | `TAKE_DAMAGE` | 自己受到匹配技能伤害后 |
| 造成击杀 | `KILL` | 自己技能击杀后 |

### 7.4 技能充能 · 范围下拉（完整）

| 后台文案 | 再填 | 含义 |
|----------|------|------|
| 任意 | — | 任意技能 |
| 指定类型 | 普攻/小技能/大招 | 该类型 |
| 指定流派 | 流派文本 | 同流派 |
| 指定元素类型 | 元素 | 同元素 |
| 指定技能 | 主动技下拉 | 仅该 id |

### 7.5 和「全局能量」对照

剧情里的「能量 30/50」**不是**本后台模型。本模型是：**need=3** +「释放 · 指定类型 · 普攻 · +1」。

## 8. 释放与效果 · 三种输出

每张输出卡片（主动技与战斗被动相同控件）：

### 8.1 公共

| 控件 | 说明 |
|------|------|
| 选择目标 | 见下表 |

| 排序 / 备注 | — |

### 8.4 输出类型 = 追加BUFF

| 控件 | 说明 |
|------|------|
| BUFF 定义 | 下拉来自「BUFF 配置」已存条目 |
| 目标 + 概率 | — |

须先在 BUFF 页建好定义，再在这里引用。

## 9. 被动技能各页怎么编

各页点「+ 新增被动」打开抽屉；标题形如「新增被动 · 高级属性」。  
**类型由当前菜单页锁定**，表单里不再改 `passiveType`。

### 9.0 所有被动共有：第一部分 · 生效条件

| 模式 | 含义 |
|------|------|
| 不限 | 始终可生效 |
| 选择 | 下方条件组 **全部同时满足** 才为 true |

「选择」时可「添加条件」，类型：

| 后台文案 | 再填 |
|----------|------|
| 装备了指定装备 | 装备下拉 |
| 装备了指定类型装备 | 武器/护甲/… |
| 装备了指定技能 | 主动技 |
| 装备了指定类型技能 | 普攻/小/大 |
| 公式判定 | 左公式 · 比较 · 右公式 |

比较符：大于 / 大于等于 / 小于 / 小于等于 / 等于。

### 9.1 基础属性 / 高级属性

见 §4。效果区是「添加效果」数值行，**不是** SkillOutput 卡片。

保存后：到装备「被动技能」挂槽 → 开战前固化进面板。

### 9.2 开战锚点（`BATTLE_START`）

**第二部分 · 开战锚点**

| 施加规则（pill） | 再填 |
|------------------|------|
| 开战立即 | — |
| 达到行动值后单次 | 行动值阈值 |
| 每达到行动值脉冲 | 行动值间隔 |

灰字提醒：计时用**全局已经过行动值**；造成伤害时目标请选敌方，不要选「自己」。

**第三部分 · 技能输出**：与主动技相同的输出卡片（§8）。

### 9.3 角色数值判定锚点（`BATTLE_JUDGE`）

**第二部分 · 判定条件**：比较符 + 上公式 / 下公式。  
实时：成立则套用输出，不成立则取消（语义见界面灰字）。

**第三部分 · 技能输出**。

### 9.4 角色数值脉冲锚点（`BATTLE_PULSE`）

**第二部分 · 脉冲条件**：

- 触发方式固定文案「每当达到」  
- 本场最多触发次数（0=不限）  
- 上公式每跨过下公式一个阈值阶梯触发一次  

**第三部分 · 技能输出**。

### 9.5 角色战斗事件锚点（`BATTLE_COMBAT`）

**第二部分 · 战斗事件**

事件下拉（完整）：

| 文案 | 枚举 |
|------|------|
| 造成主动技能伤害后 | `AFTER_DEAL_ACTIVE_DMG` |
| 受到主动技能伤害后 | `AFTER_TAKE_ACTIVE_DMG` |
| 释放技能后 | `AFTER_CAST_SKILL` |
| 受到技能后 | `AFTER_RECEIVE_SKILL` |
| 受到脉冲BUFF伤害后 | `AFTER_TAKE_PULSE_BUFF_DMG` |
| 击杀时 / 被击杀时 | `AFTER_KILL` / `AFTER_KILLED` |
| 触发闪避后 | `AFTER_DODGE` |

部分事件可再配 **技能匹配**（任意 / 指定类型 / 流派 / 元素 / 技能）——与充能五维相同。

**第三部分 · 技能输出**；事件专属目标在此页才有意义。

## 10. BUFF 配置抽屉

路径：`技能管理 → BUFF 配置` →「+ 新增 BUFF」。

技能/被动里「追加BUFF」只是引用这里的 id。

### 10.1 第一部分 · 基础

| 控件 | 选项 |
|------|------|
| 名称 / 编码 / 排序 / 备注 / 启用 | — |
| 类型 | 属性 BUFF / 脉冲 BUFF / 判定属性 BUFF / 判定爆发 BUFF / 闪避 BUFF |
| 效果标签 | 增益 / 减益 |
| 驱散 | 可驱散 / 不可驱散 |
| 叠加 | 不可叠加 / 可叠加（可填最大层数，0=不限） |
| 持续 | 战斗内永久 / 自定义行动值 |

### 10.2 按类型出现的后续区块

| 类型 | 后续区块 |
|------|----------|
| **闪避 BUFF** | 闪避概率% + 技能匹配（五维） |
| **判定属性 / 判定爆发** | 比较符 + 上/下公式 |
| **属性 BUFF** 或 **判定属性** | 属性 + 增减 + 修改量公式 |
| **脉冲 BUFF** | 间隔行动值；效果伤害/治疗；元素；结算目标；公式（自己=施加者，每个目标=持有者） |
| **判定爆发** | 爆发：伤害 / 治疗 / 属性修改 + 公式；成立结算一次后移除 |

闪避灰字：持有期间被匹配技能命中 → 按概率伤害变 0 → 可触发被动「触发闪避后」。

## 11. 公式画布与「添加参数」

出现位置：所需充能公式、输出伤害/治疗/属性量、被动条件左右式、判定/脉冲上下式、BUFF 公式等。

### 11.1 画布操作

1. 点「参数」→ 弹出「添加参数」  
2. 或点 `+ − × ÷ ( )` 直接加运算符 token  
3. token 可拖拽排序（部分画布）；点 token 上 × 删除  
4. 「手动」token 可直接改数字  

保存时序列化为 JSON 数组（`formulaJson` / `needChargeFormulaJson` 等）。

### 11.2 「添加参数」弹层

| 方式 | 含义 |
|------|------|
| 手动输入 | 填字面量，如 `1.2` |
| 读取 | 选读取角色 + 分类 + 具体项 |

**读取角色**（随语境变化，常见）：自己 / 每个目标 / 全局 / 阵营汇总等。

**读取分类**：

| 分类 | 再选 |
|------|------|
| 属性 | 当前生命（战斗内）/ 最大生命 / 攻击 / 防御 / 角色行动值 |
| 伤害 | 方向：造成/受到；统计：累计伤害量 / 次数 / 主动技能伤害次数 |
| 技能 | 范围（任意/类型/流派/元素/指定）+ 次数类型（释放次数/受到次数） |
| 锚点 | 仅部分战斗被动输出语境；伤害值等 |

**全局**读取项：已经过行动值。

常见伤害公式在画布上等价于：

```text
[读取 · 自己 · 属性 · 攻击]  [×]  [手动 · 1.2]
```

## 12. 挂载：装备 / 怪物 / 关卡 / 掉落 / 配方

### 12.1 装备管理（按部位分页）

行内按钮：

| 按钮 | 作用 |
|------|------|
| 详情 | 看面板、已挂普攻/充能技/被动摘要 |
| 编辑 | 物品基础字段 + 武器 ATK/攻速 或 防具 HP/DEF |
| **普攻**（仅武器） | 打开技能抽屉，类型锁定普攻；保存后写入武器普攻槽 |
| **充能技能** | 多行选小技能/大招；未选中的行保存时剔除 |
| **被动技能** | 每行：先选被动**类型**再选该类型下的被动 |
| 配方 | 以本装备为产出物编合成（见下） |

玩家穿戴后开战装入。

### 12.2 怪物角色管理

抽屉字段：名称、分类、稀有度、占地、基础攻/血/防/**基础行动值**，以及：

| 槽 | 下拉过滤 |
|----|----------|
| 普攻槽 | 普攻技；空=通用普攻 |
| 小技能槽 | 小技能 |
| 大招槽 | 大招 |

占地：普通 1×1 / 稀有 1×2 / 史诗 2×2 / BOSS 2×4；特殊可手改。

### 12.3 关卡 · 布置

`关卡模式管理 → 主线（等）` → 选中小关 → 右侧 **怪物布置（6×5）**：拖怪物落格 / 添加后随机落位。

### 12.4 怪物掉落

`物品系统 → 怪物掉落`：怪物 + 物品 + 掉落率(100=100%，独立判定) + min/max 数量。

### 12.5 配方

`物品系统 → 配方管理` 或装备行「配方」：

- 产出物品 / 数量  
- **解锁章节（进入该章即可合成；空=不限）**  
- 多行材料

## 13. 端到端示例（按后台点一遍）

### 例 A：光刃横扫（普攻攒 3 次放，打敌方全部）

1. **充能技能管理 → 新增**  
   - 类型：小技能；元素：物理  
2. **所需充能** → 手动输入 → `3`  
3. 充能条件类型选「充能条件-技能充能」→ 事件「释放」→ 范围「指定类型」→「普攻」→「添加充能条件」→ 增加充能 `1`  
4. **添加输出** → 目标「敌方全部」→ 输出类型「效果」→ 伤害 → 物理 → 段数 1  
5. 公式：参数「读取 / 自己 / 属性 / 攻击」→ `×` → 手动 `1.2`  
6. 保存  
7. **装备管理 → 武器 → 充能技能** → 添加该技能 → 确认保存  

### 例 B：能量突闪（闪避 BUFF）

1. **BUFF 配置 → 新增**  
   - 类型：闪避 BUFF；持续：自定义行动值 `100`  
   - 闪避概率 `45`；技能匹配「任意」  
2. 保存  
3. **充能技能** 新建小技能，need 手动 `8`  
4. 两条技能充能：① 释放+指定类型+普攻+1；② 受到伤害+任意+1  
5. 输出：追加BUFF → 选刚建的闪避 → 目标「自己」  
6. 挂到武器充能技能槽  

### 例 C：高级属性「造成伤害 +20%」挂护甲

1. **基础属性被动 → 高级属性 → 新增**  
2. 生效条件「不限」  
3. 添加效果：造成伤害比例（叠乘）/ 增加 / `20`  
4. 保存  
5. **护甲管理 → 被动技能** → 类型选「高级属性」→ 选中该被动 → 保存  

### 例 D：怪物带漏电溅射

1. 充能技能里配好小技能（行动值 x=120 y=24，need=24，输出电击打敌方全部）  
2. **怪物角色管理 → 编辑** → 小技能槽选该技 → 保存  
3. 主线小关布置该怪
