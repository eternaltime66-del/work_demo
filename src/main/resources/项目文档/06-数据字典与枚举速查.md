# 数据字典与枚举速查

> 字段以 Java 实体为基线；通用 ID、创建/更新时间和逻辑删除等继承字段未在每张表重复列出。数据库类型、索引和默认值仍应以部署数据库 DDL 为准。

## 1. 账号与公共数据

| 表 | 实体 | 关键内容 |
|---|---|---|
| `app_member` | `Member` | 邮箱、密码/token 相关身份数据、会员角色与状态 |
| `app_point_wallet` | `PointWallet` | uid、币种、余额 |
| `app_point_pay_order` | `PointPayOrder` | 订单类型、状态、币种、数量和业务流水 |
| `wx_super_param` | `WxSuperParam` | 系统参数键值 |
| `wx_more_lang` | `WxMoreLang` | 多语言文本 |

账号角色 `MemberRole` 至少区分普通玩家与后台管理身份；所有受保护接口应显式声明允许角色。

## 2. 角色字段

### `app_role_base_stat` / `RoleBaseStat`

模板字段组：

- 身份：`id/name/sort/remark/defaultOwn/mainRole/roleCategory`；
- 基础：`baseAtk/baseHp/baseDef/baseAction/baseAtkSpeed`；
- 额外：`extraAtk/extraHp/extraDef`；
- 通用倍率：`dealDmgRatio/takenDmgRatio`；
- 类型倍率：`dealElementDmgRatio/takenElementDmgRatio/dealPhysDmgRatio/takenPhysDmgRatio`；
- 高级：`lifeStealRatio/finalAtkRatio/finalHpRatio/finalDefRatio`；
- 攻速：`atkSpeedUpRatio/atkSpeedDownRatio`；
- 召唤预留：`inheritAtkRatio/inheritDefRatio/inheritHpRatio`。

### `app_player_role` / `PlayerRole`

基本复制模板字段，额外保存 `uid/baseStatId`。`display*`、`equipBonus*` 和技能列表是非持久化展示组合字段。

### 角色关系表

| 表 | 关键字段 |
|---|---|
| `app_player_role_skill` | `roleId/skillId/sort` |
| `app_player_layout` | `uid/roleId/posCol/posRow`；其余角色信息主要用于展示 |

`PlayerRoleCategory`：`HERO`、`PARTNER`、`SUMMON`。

## 3. 物品与装备字段

### `app_item`

- 标识：`code/name/icon/itemType`；
- 库存：`maxStack`；
- 管理：`sort/enable/remark`；
- 插槽计数：充能技能、基础/高级/旧锚点/旧周期/旧持续、V2 战斗开始/判定/脉冲/事件被动；
- 每类插槽同时存在默认玩家可编辑数和最大可编辑数，但玩家自定义链尚未完整实现。

### 扩展表

## 5. 怪物、关卡与进度字段

### 怪物

`app_monster`：名称、稀有度、角色分类、网格宽高、基础攻血防/行动、排序备注、普通/小/大招 ID，以及与角色相同的一组高级倍率和元素字段。

`MonsterRarity`：

| 值 | 默认占地 |
|---|---|
| `NORMAL` | 1×1 |
| `RARE` | 1×2 |
| `EPIC` | 2×2 |
| `BOSS` | 2×4 |
| `SPECIAL` | 可自定义 |

`app_monster_drop`：`monsterId/itemId/dropRate/minQty/maxQty/sort/enable/remark`。

### 关卡

| 表 | 关键字段 |
|---|---|
| `app_stage` | `parentId/kind/name/code/sort/enable/remark/staminaCost/dailyMaxAttempts` |
| `app_stage_level_monster` | `levelId/monsterId/posCol/posRow/sort/remark` |
| `app_stage_first_reward` | `stageId/itemId/qty/sort` |
| `app_player_stage_level` | `uid/levelId/cleared/firstRewardClaimed/attemptDate/attemptCount` |
| `app_player_stage_chapter` | `uid/chapterId/cleared/firstRewardClaimed` |
| `app_player_stamina` | `uid/stamina/maxStamina` |
| `app_player_tower_run` | `uid/status/currentLevelId/allyHpJson` |

`StageKind`：`TYPE/CHAPTER/LEVEL`。模式 code 常量：`MAIN/TOWER`。塔状态：`RUNNING/CLEARED/DEAD`。

## 6. 主动技能字段

### `app_active_skill`

- 身份：`name/code/skillType/skillSchool/damageElement/sort/enable`；
- 充能：`needChargeMode/needCharge/needChargeFormulaJson`；
- 次数限制：单技能、全局、所有手段、单角色等 max cast 字段；
- 兼容字段：`formulaJson`；
- 描述：`remark/more`。

`ActiveSkillType`：`NORMAL/ULTIMATE/SMALL`。

`NeedChargeMode`：`SELF_BASE_ACTION/MANUAL/FORMULA`。

### `app_skill_charge`

`skillId/name/conditionType/scope/everyActionValue/chargeGain/skillChargeEvent/skillChargeMatch/matchSkillType/matchSkillSchool/matchDamageElement/matchSkillId/sort`。

事件：`CAST/RECEIVE/DEAL_DAMAGE/TAKE_DAMAGE/KILL`。

匹配：`ANY/ANY_TYPE/ANY_SCHOOL/ANY_ELEMENT/SPECIFIC`。

### `app_skill_output`

主动和被动共用：`skillId` 或 `passiveSkillId`、名称、输出类型、目标、属性键/方向、效果类型、元素、公式、段数、触发率、持续 AV、Buff ID、排序和描述。

输出类型：`ATTR/EFFECT/APPEND_BUFF`。效果类型：`DAMAGE/HEAL/ATTR_MODIFY`。

`app_skill_effect` 与其字段类似，是旧技能效果兼容表。

## 7. 被动与 Buff 字段

### `app_passive_skill`

- 身份：`name/code/passiveType/sort/enable`；
- 前置条件模式；
- 技能类型、流派、元素与指定技能匹配；
- 左右公式和比较符；
- 每场最大触发；
- V2 战斗事件；
- 开战施加规则与 AV；
- 描述字段。

被动类型：

- 战外：`OUT_BASIC/OUT_ADVANCED`；
- 战斗：`BATTLE_START/BATTLE_JUDGE/BATTLE_PULSE/BATTLE_COMBAT`。

关系表：

| 表 | 用途 |
|---|---|
| `app_passive_condition` | 装备物品/类型、装备技能/类型、公式比较 |
| `app_passive_effect` | 战外属性键、方向、数值 |
| `app_skill_output` | 主动技能与战斗被动的统一输出 |

### `app_buff_def`

包含 Buff 类型、增益/可驱散、叠加方式/上限、持续 AV、属性修改、公式、脉冲间隔与类型/元素/目标、判定左右公式、闪避率与匹配技能条件。

`BuffKind`：`ATTR/PULSE/JUDGE_ATTR/JUDGE_BURST/DODGE`。

## 8. 属性键

`AttrModifyKey` 与战外被动键覆盖：

- 平坦：`ATK/MAX_HP/DEF`；
- 加法百分比：`LIFE_STEAL/ATK_SPEED/FINAL_ATK/FINAL_HP/FINAL_DEF`；
- 乘法百分比：`DEAL_DMG_RATIO/TAKEN_DMG_RATIO/DEAL_ELEMENT_DMG_RATIO/TAKEN_ELEMENT_DMG_RATIO/DEAL_PHYS_DMG_RATIO/TAKEN_PHYS_DMG_RATIO`。

元素：`PHYSICAL/POISON/IGNITE/FREEZE/SHOCK/BURN`。

方向：`INCREASE/DECREASE`。比较：`GT/GTE/LT/LTE/EQ`。

## 9. 公式读取

读取角色：

- 单位：`SELF/EACH_TARGET/SPECIFIC_TARGET`；
- 聚合：`ALL_ALLY/ALL_ENEMY`；
- 全局：`GLOBAL`；
- 事件：受击目标、施法者、伤害来源、被伤害目标等锚点角色。

读取键：

- 当前面板：`MAX_HP/HP/ATK/DEF/ACTION`；
- 全局：`ELAPSED_ACTION`；
- 累计量：造成/受到伤害与治疗；
- 累计次数：造成/受到伤害与治疗；
- 元素：全局元素加成和每种元素加成；
- 技能统计：结合技能匹配模式读取释放/受击等计数。

## 10. 目标枚举分组

- 自身：`SELF`；
- 己方单体：首位、随机、当前/最大/百分比生命极值、攻击极值；
- 己方群体：全体、前排、后排；
- 敌方单体：同类极值与随机；
- 敌方群体：全体、前排、后排；
- 全场：生命/攻击极值、全体、前排、后排；
- 事件：受击目标、施法者、伤害源、脉冲施法者、击杀方、被击杀方、特定目标；
- `SPECIAL` 及若干 deprecated 旧锚点值仅作兼容/占位。

## 11. 配置校验原则

后台保存时至少验证：

- 枚举值合法，引用 ID 存在且启用；
- 概率 0~100、数量非负、min ≤ max；
- 段数、持续和脉冲间隔为合理正数；
- 公式 JSON 可解析，节点读取组合合法；
- 输出只能绑定主动技能或被动之一；
- Buff 类型对应字段完整且不携带冲突字段；
- 装备扩展类型与 `Item.itemType` 一致；
- 关卡父子 kind 合法、怪物不越界不重叠；
- 玩家资产表具有必要唯一索引。
