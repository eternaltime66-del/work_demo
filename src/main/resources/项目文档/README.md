## 2. 一句话定位

Game3 是一个 Java 17 + Spring Boot 3 的 Web RPG 单体应用。后台负责配置角色、怪物、技能、Buff、物品、配方和关卡；玩家端完成注册登录、布阵备战、装备与库存管理、合成、主线及无尽塔战斗；战斗由服务端完整演算，前端按事件流播放。

## 3. 两条核心闭环

### 内容生产闭环

```text
后台创建角色/怪物
  → 创建主动技能、被动、Buff
  → 把技能/被动绑定到角色、怪物或装备
  → 创建物品、掉落、配方
  → 创建关卡树并布置怪物
  → 玩家端读取并游玩
```

### 玩家成长闭环

```text
注册/登录
  → 获得默认角色
  → 布阵
  → 挑战关卡
  → 怪物掉落进入仓库
  → 材料合成装备
  → 装备与技能改变战斗面板
  → 挑战更高关卡/无尽塔
```

## 4. 当前规模

- Java 源文件：326 个。
- 核心游戏模块：`wxBusiness/game`，包含实体、Mapper、Service、战斗引擎、枚举和 VO。
- 静态页面：玩家端 6 个、后台 1 个。
- 前端形态：HTML + CSS + 原生 JavaScript + Vue 3 production runtime，无 npm 构建步骤。
- 持久化：MySQL + MyBatis-Plus。
- 运行态基础设施：Redis、Spring AOP、异步任务与调度。
- 自动化测试：当前 16 项，覆盖战斗核心、Redis 锁和掉落配置；数据库集成与并发压力测试仍待补齐。
