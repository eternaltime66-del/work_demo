Game3 UI 美化方案 v1 — 结构与交互重构
适用范围：登录页、首页、备战、布局、合成、出击（战斗页面暂不涉及） 执行原则：保留现有紫青霓虹深色调，不推翻视觉基调；本轮只做设计令牌统一、布局密度、层级秩序、交互一致性、素材位预留。 本轮不引入任何图片素材，所有图标位先用占位容器 + 现有 emoji 兜底，第二轮再替换。
0. 必须先修的 5 个硬伤
按优先级排序，这些不修，后面美化都是在流沙上盖楼。
0.1 【严重】备战页拖拽在移动端完全失效
prep 面板用的是 HTML5 Drag and Drop（draggable + dragstart/dragover/drop），iOS Safari 与安卓 Chrome 的触屏不触发这套事件。而 layout 面板用的是 pointerdown + layout-finger-ghost 自绘拖拽，是正确做法。
要求：把 prep 的拖拽统一迁移到 layout 已有的 Pointer Events 方案，抽成公共 composable：
/js/composables/useDragMove.js
  导出 useDragMove({ onPick, onHover, onDrop })
  - pointerdown  → 记录起点，setPointerCapture，200ms 或位移 >6px 才判定为拖拽（否则视为 click）
  - pointermove  → 更新 ghost 位置，用 document.elementFromPoint 命中放置区
  - pointerup    → 命中则 onDrop，否则回弹
  - touch-action: none 加在可拖元素上
layout 与 prep 都改用它，删除所有 dragstart/dragover/dragenter/dragleave/drop/dragend 处理器与 draggable 属性。ghost 组件统一为 .drag-ghost（合并现有 .layout-finger-ghost 与 .fm-finger-ghost）。
